# Release manifests

These compact files summarize the RNASSTR v2 partitions and benchmark subsets. The complete partition CSV files and full per-sequence model outputs are stored in the associated Zenodo archive because they exceed practical GitHub file-size limits.

`structural_splits/` contains the final family assignments, component summaries, clan and structural edges, leakage checks, and family lists generated by the `v3_fast10` partitioning workflow. The resulting partitions contain 2,795 training families, 648 validation families, and 636 test families, for a total of 4,079 Rfam families.
